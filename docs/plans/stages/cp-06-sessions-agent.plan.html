Chat with the agent, and the agent writes

cp-06 · 2026-10-28 · final · pratos with Claude Code · 4 min read · built from docs/plans/stages/cp-06-sessions-agent.plan.json

Beside the plan, people start a Session, ask the agent and steer its Run. The agent is a Participant: just agent-serve answers queued Runs through the same API, and "/ask" in the editor has it write into the plan with EditPlan, credited. It survives kill -9 through pi-durable.

Where we are

cp-05 has the plan document: Threads and Decisions in each PlanRoom's events table, the live socket, resolve-thread checked in decide(), and just review. Nobody can ask the agent anything, no route sets by from the sign-in, and packages/agent does not exist.

  • Sessions run on the engine over the room's own SQLite (the durableObject adapter), so events and their projections commit in one transaction.
  • StartSession makes the agent a Participant from the start (AGENT in session/decider.ts), so the agent never has to join.
  • pi-durable finds a submission by requestId; with the Run id as requestId, a restarted agent resumes the same answer instead of asking twice.
  • The panel's server functions reach the API over the binding, but agent-serve and curl need an HTTP door: /api on the web origin.
  • With no model key, chooseModelOrFaux answers through pi-durable all the same, with a faux model that echoes the question.

Where we end up

On /plans/gh-12, ask in a Session and just agent-serve answers within seconds. "/ask a three step rollout plan" in the editor: the agent's text replaces the line. Kill the agent mid-answer and restart it: the Run finishes once.

Not doing

Out of scope for this plan, each with the reason in the same line.

  • Failing a Run after repeated errors; FailRun arrives in a later stage.
  • Tools for the agent; it answers in words, three sentences at most.
  • Running the agent inside the Durable Object; see the decision.
  • Renaming Session to Thread; that waits for the post-workshop rename.
  • Restyling the panel; cp-07 gives it bubbles and the theme's classes.

Approach
