End-to-end tests across the product, bugs fixed test-first

cp-09 · 2026-10-28 · final · pratos with Claude Code · 2 min read · built from docs/plans/stages/cp-09-e2e.plan.json

The stories prove each part; nothing yet proves a person can use the whole product in a browser. This stage adds four flows a person walks, with the real agent answering, and one rule: every bug found is a failing test before it is a fix.

Where we are

cp-08 has every story green: the domain, the agent loop on in-memory SQLite, pi-durable after a restart. just e2e runs three browser tests, all on the admin pages. No browser signs up, decides, or gets an answer from the agent.

  • A form submitted before React hydrates posts natively; __root.tsx sets <html data-hydrated>, and ready() in e2e/helpers.ts waits for it.
  • Playwright matches button names as substrings, so a session titled 'Start here' matches Start; buttons use exact: true.
  • agent-serve keeps its pi-durable store in one default file; a test's agent needs its own AGENT_STORE or it shares yours.
  • Each run uses a fresh plan, e2e-<time>, so no plan room carries an earlier run's threads.
  • e2e/playwright.config.ts migrates, seeds and starts the app unless :3000 already answers.

Where we end up

just e2e runs seven tests in a real browser, green: three admin tests and four flows, one with the real agent answering two people. Every bug fixed here has a test that failed first.

Not doing

Out of scope for this plan, each with the reason in the same line.

  • A real model in tests; the faux model is deterministic and free.
  • Screenshot comparisons; small visual issues go through Agentation notes.
  • Running just e2e in CI; it stays a local recipe for now.
  • kill -9 in a browser test; brain.test.ts covers the restart.

Approach

Helpers first, because every flow waits on them. Then the agent process the flows share. Then the four flows. Bugs met on the way follow the rule.

Decisions

Each real choice in this plan, with the options compared side by side. A decided one is locked on its choice; open “Compare the options” to see why.
