# Greenhouse · product

**Who uses it.** A small team and an agent planning one change in one repo: the person who asked, the people who will build it, and the agent that explores and answers.

**The job.** Turn a question into a decision someone owns, dated and attached to the part of the plan it changed, with the agent doing the legwork in the open where everyone can see each step.

**What it is.** A plan document on the left: blocks, comment threads on blocks, each ending in a decision. A chat panel on the right: sessions where people ask the agent, steer it while it works, and read its answers. One plan room holds both, so everyone watching sees the same thing at once.

**What it will not become.** A chat app with a document attached; a ticket tracker; a place where the agent decides. People decide; the agent explores, drafts and answers.

**How we know it works.** A decision recorded per plan per week, and the share of decisions that cite an agent answer.
